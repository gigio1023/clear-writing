# Document Modes

Choose the narrowest mode that solves the user's actual problem.

## `correction`

Use when the source already has a usable structure and enough context.

Typical requests:

- "AI스럽지 않게 다듬어줘"
- "humanize this"
- "tone this down"
- "문장만 자연스럽게"

Focus:

- sentence-level rewrites
- cadence fixes
- abstraction reduction
- minor section cleanup

## `compose`

Use when the source is not yet a usable document.

Typical requests:

- "이 메모를 문서로 정리해줘"
- "rewrite this into a readable memo"
- "organize these notes"
- "standalone doc로 만들어줘"

Focus:

- result-first structure
- missing context
- terminology stability
- explicit evidence, assumptions, and open questions

## `hybrid`

Use when both issues are present, which is common in long drafts.

Typical requests:

- "읽기 좋게 다시 써줘"
- "deslop and reorganize this"
- "AI 티 안 나게 문서 전체를 고쳐줘"

Focus:

- structure first where necessary
- sentence-level cleanup throughout
- preserve facts while improving both credibility and readability
