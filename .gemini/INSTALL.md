# Install humanize-doc for Gemini CLI

## Preferred

```bash
npx skills add gigio1023/humanize-doc@humanize-doc --agent gemini-cli
```

## Manual install

```bash
git clone https://github.com/gigio1023/humanize-doc.git ~/.gemini/humanize-doc
mkdir -p ~/.gemini/skills
cp -R ~/.gemini/humanize-doc/humanize-doc ~/.gemini/skills/
```

Restart Gemini CLI after copying.
