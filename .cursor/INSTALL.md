# Install humanize-doc for Cursor

## Preferred

```bash
npx skills add gigio1023/humanize-doc@humanize-doc --agent cursor
```

## Manual install

```bash
git clone https://github.com/gigio1023/humanize-doc.git ~/.cursor/humanize-doc
mkdir -p ~/.cursor/skills
cp -R ~/.cursor/humanize-doc/humanize-doc ~/.cursor/skills/
```

Restart Cursor after copying.
